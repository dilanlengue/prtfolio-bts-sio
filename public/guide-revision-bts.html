2.1 — Active Directory & DNS (Windows Server 2025)

Epreuve E5 | Domaine sio.lan | Serveur SVR-WND | IP 172.16.1.1 | Competences B2.1, B2.2, B3.2, B3.3
Qu'est-ce qu'Active Directory et a quoi sert-il ?
Active Directory (AD) est un service d'annuaire developpe par Microsoft qui permet de centraliser la gestion des ressources d'un reseau : utilisateurs, ordinateurs, groupes et politiques de securite. Il repose sur le protocole LDAP pour l'interrogation de l'annuaire et Kerberos pour l'authentification. Dans mon projet, AD DS me permet de gerer tous les comptes utilisateurs depuis un seul point, de les organiser en Unites d'Organisation (OU), et d'appliquer des politiques de securite uniformes a l'ensemble du domaine sio.lan. Sans AD, chaque poste devrait etre administre individuellement, ce qui serait ingerable dans une entreprise.
Pourquoi avoir choisi Windows Server 2025 ? Quelles differences avec 2022 ?
J'ai utilise Windows Server 2025 car c'est la version la plus recente, ce qui me permet de travailler avec les fonctionnalites les plus actuelles. Par rapport a Windows Server 2022, la version 2025 apporte des ameliorations en termes de securite (notamment le support de TLS 1.3 par defaut), des performances ameliorees pour Hyper-V, et une meilleure integration avec les services cloud Azure. Le processus d'installation et de configuration d'AD DS reste similaire entre les deux versions, mais il est important de se former sur la derniere version pour etre a jour en entreprise.
Expliquez les etapes de promotion d'un serveur en controleur de domaine.
D'abord, j'ai configure l'IP statique du serveur SVR-WND en 172.16.1.1 et defini le DNS prefere sur 127.0.0.1 (lui-meme). Ensuite, j'ai installe le role AD DS via le Gestionnaire de serveur, onglet "Ajout de roles et fonctionnalites". Apres l'installation du role, j'ai lance l'assistant de promotion en controleur de domaine ou j'ai selectionne "Ajouter une nouvelle foret" avec le nom de domaine sio.lan. L'assistant cree automatiquement la zone DNS integree avec les enregistrements SRV necessaires (_ldap, _kerberos). Enfin, le serveur redemarre et devient le premier controleur de domaine de la foret.
Quelle difficulte avez-vous rencontree et comment l'avez-vous resolue ?
La principale difficulte a ete un echec de promotion du serveur en controleur de domaine avec une erreur de prerequis DNS. Le probleme venait du fait que le serveur n'avait pas de serveur DNS configure dans ses parametres reseau. J'ai resolu le probleme en configurant le DNS prefere sur 127.0.0.1, c'est-a-dire le serveur lui-meme, avant la promotion. Cela permet l'installation automatique du DNS integre. Une deuxieme difficulte a ete l'absence des enregistrements SRV (_ldap, _kerberos) dans la zone DNS apres la promotion. J'ai resolu cela en redemarrant le service Netlogon avec les commandes "net stop netlogon" puis "net start netlogon" pour forcer la recreation de ces enregistrements indispensables a la localisation du controleur de domaine.
Qu'est-ce qu'une OU et pourquoi en creer ?
Une Unite d'Organisation (OU) est un conteneur dans Active Directory qui permet d'organiser logiquement les objets de l'annuaire (utilisateurs, groupes, ordinateurs). Les OU refletent generalement la structure de l'entreprise : par service (IT, RH, Comptabilite), par site geographique, ou par type de personnel (employes, stagiaires). L'interet principal des OU est de pouvoir y lier des GPO (Strategies de Groupe) pour appliquer des politiques specifiques a un groupe d'objets. Par exemple, dans mon projet, j'ai cree une OU "Stagiaires" pour y appliquer des restrictions specifiques via GPO.
Qu'est-ce que le DNS integre a Active Directory et quel est son avantage ?
Le DNS integre a Active Directory stocke les zones DNS directement dans la base de donnees AD au lieu de fichiers texte. Cela presente plusieurs avantages : la replication DNS est automatiquement geree par la replication AD (pas besoin de transferts de zone separees), la securite est renforcee car seuls les controleurs de domaine autorises peuvent modifier les enregistrements, et les mises a jour dynamiques securisees sont possibles. Dans mon projet, la zone directe sio.lan a ete creee automatiquement lors de la promotion du serveur, avec les enregistrements SRV necessaires au fonctionnement du domaine.
Quels protocoles utilise Active Directory ?
Active Directory utilise principalement trois protocoles. LDAP (Lightweight Directory Access Protocol) sur le port 389 permet d'interroger et de modifier l'annuaire. Kerberos sur le port 88 gere l'authentification des utilisateurs et des services avec un systeme de tickets securises. DNS (Domain Name System) sur le port 53 permet la localisation des controleurs de domaine grace aux enregistrements SRV. Active Directory utilise aussi le protocole de replication DFS-R pour synchroniser les donnees entre controleurs de domaine, et NTLM comme protocole d'authentification de secours quand Kerberos n'est pas disponible.
Ce projet couvre quelles competences SISR exactement ?
Ce projet couvre quatre competences du referentiel. B2.1 "Concevoir une solution d'infrastructure reseau" car j'ai du concevoir l'architecture du domaine (nom de foret, plan d'adressage, structure des OU). B2.2 "Installer, tester et deployer une solution d'infrastructure reseau" car j'ai installe et configure AD DS et DNS sur le serveur. B3.2 "Preserver l'identite numerique de l'organisation" car la gestion centralisee des comptes utilisateurs et des droits d'acces protege les identites. B3.3 "Securiser les equipements et les usages des utilisateurs" car l'authentification centralisee via Kerberos et les politiques de mot de passe renforcent la securite des postes.

2.2 — Segmentation VLAN (Cisco Packet Tracer)

Epreuve E5 | VLAN 10 IT, VLAN 20 Compta, VLAN 30 RH, VLAN 99 Wi-Fi | Switch 2960, Router-on-a-Stick | Competences B2.1, B2.2, B2.3, B3.5
Qu'est-ce qu'un VLAN et pourquoi segmenter un reseau ?
Un VLAN (Virtual Local Area Network) est un reseau local virtuel qui permet de segmenter logiquement un reseau physique en plusieurs sous-reseaux isoles. La segmentation VLAN presente trois avantages majeurs : la securite (les flux du service RH ne sont pas visibles par le service IT), la performance (reduction des domaines de broadcast, donc moins de trafic inutile sur le reseau) et l'administration (possibilite d'appliquer des regles differentes par service). Dans mon projet, j'ai cree 4 VLAN pour isoler les services IT, Comptabilite, RH et le Wi-Fi invite d'une PME.
Expliquez la difference entre un port access et un port trunk.
Un port en mode access appartient a un seul VLAN et transporte les trames sans etiquette 802.1Q. C'est le mode utilise pour connecter les postes de travail : on configure "switchport mode access" puis "switchport access vlan X". Un port en mode trunk peut transporter les trames de plusieurs VLAN simultanement en ajoutant une etiquette 802.1Q a chaque trame pour identifier a quel VLAN elle appartient. Le trunk est utilise entre les switches ou entre le switch et le routeur. Dans mon projet, le port connectant le switch 2960 au routeur est en mode trunk pour permettre le routage inter-VLAN.
Comment fonctionne le Router-on-a-Stick ? Pourquoi cette methode ?
Le Router-on-a-Stick est une methode de routage inter-VLAN qui utilise une seule interface physique du routeur, divisee en sous-interfaces logiques. Chaque sous-interface est associee a un VLAN avec la commande "encapsulation dot1Q [numero_vlan]" et recoit une adresse IP qui sert de passerelle par defaut pour ce VLAN. Le trafic entre VLAN passe par le trunk jusqu'au routeur, qui route le paquet vers la bonne sous-interface et le renvoie sur le trunk avec le bon tag VLAN. J'ai choisi cette methode car elle ne necessite qu'un seul lien physique entre le switch et le routeur, ce qui est economique pour une PME. L'alternative serait un switch de couche 3 capable de faire du routage inter-VLAN directement.
A quoi sert le VLAN 99 Wi-Fi invite ? Pourquoi l'isoler ?
Le VLAN 99 (192.168.99.0/24) est dedie aux visiteurs qui se connectent au Wi-Fi de l'entreprise. Il est isole des VLAN internes (10, 20, 30) pour des raisons de securite : les visiteurs ne doivent pas avoir acces aux ressources internes de l'entreprise (serveurs de fichiers, imprimantes, applications metier). Ce VLAN permet aux invites d'acceder uniquement a Internet. En production, on ajouterait des ACL (Access Control Lists) sur le routeur pour bloquer explicitement le trafic du VLAN 99 vers les VLAN internes tout en autorisant le trafic vers Internet.
Comment fonctionne le DHCP avec les VLAN ? Expliquez le ip helper-address.
Le DHCP utilise des messages broadcast (DHCPDISCOVER) qui ne traversent pas les limites des VLAN. Si le serveur DHCP est sur un autre VLAN que le client, les requetes DHCP n'arriveront jamais au serveur. La commande "ip helper-address" configuree sur la sous-interface du routeur resout ce probleme : elle convertit le broadcast DHCP en unicast et le redirige vers l'adresse IP du serveur DHCP. Dans mon projet, j'ai configure des pools DHCP directement sur le routeur avec un pool par VLAN, chacun definissant la plage d'adresses, la passerelle par defaut et le serveur DNS. Le ip helper-address pointe vers le routeur lui-meme pour relayer les requetes.
Quelle difficulte avez-vous rencontree sur ce projet ?
J'ai rencontre deux difficultes majeures. Premierement, le routage inter-VLAN ne fonctionnait pas car le port du switch connecte au routeur etait configure en mode access au lieu de trunk. Les sous-interfaces du routeur ne recevaient pas les trames taguees 802.1Q. La solution a ete de passer le port en mode trunk avec "switchport mode trunk". Deuxiemement, les postes du VLAN 20 (Comptabilite) n'obtenaient pas d'adresse IP via DHCP malgre la configuration du pool. La commande "ip helper-address" manquait sur la sous-interface du VLAN 20. Apres son ajout, les requetes DHCP broadcast ont ete correctement relayees vers le pool DHCP du routeur.
Qu'est-ce que le protocole 802.1Q ?
Le protocole IEEE 802.1Q est le standard de marquage (tagging) des trames Ethernet pour identifier l'appartenance a un VLAN. Il insere un champ de 4 octets dans l'en-tete Ethernet qui contient le VLAN ID (numero du VLAN, de 1 a 4094) et un champ de priorite (802.1p pour la QoS). Quand une trame traverse un port trunk, elle est taguee avec son VLAN ID. Quand elle arrive sur un port access, le tag est retire avant d'etre envoyee au poste. Le VLAN natif est le VLAN dont les trames ne sont pas taguees sur le trunk, par defaut c'est le VLAN 1.

2.3 — Strategies de Groupe / GPO (Active Directory)

Epreuve E5 | OU Stagiaires | Blocage CMD + Panneau de configuration | Competences B2.2, B2.3, B3.2, B3.3, B3.4
Qu'est-ce qu'une GPO et comment fonctionne-t-elle ?
Une GPO (Group Policy Object) est un ensemble de parametres de configuration qui s'appliquent automatiquement aux utilisateurs et/ou aux ordinateurs dans un environnement Active Directory. Les GPO sont creees dans la console GPMC (gpmc.msc) et liees a des OU, des sites ou des domaines. Elles contiennent deux categories de parametres : la configuration ordinateur (qui s'applique au demarrage de la machine) et la configuration utilisateur (qui s'applique a l'ouverture de session). Les GPO sont appliquees dans l'ordre LSDOU : Local, Site, Domaine, OU. Si plusieurs GPO se contredisent, la derniere appliquee (la plus proche de l'objet) l'emporte.
Pourquoi avoir cree un groupe de securite en plus de l'OU ?
L'OU et le groupe de securite ont des roles differents et complementaires. L'OU est un conteneur qui sert a organiser les objets dans l'annuaire et c'est l'entite a laquelle on lie les GPO. Le groupe de securite "Groupe Stagiaires" permet de gerer les permissions d'acces aux ressources partagees (dossiers, imprimantes) et peut etre utilise dans le filtrage de securite des GPO pour cibler precisement quels utilisateurs dans l'OU sont affectes. Cela offre une granularite supplementaire : on peut avoir plusieurs groupes dans une meme OU avec des permissions differentes.
Quelles restrictions avez-vous mises en place exactement ?
J'ai configure deux restrictions via une GPO liee a l'OU Stagiaires. La premiere bloque l'acces a l'invite de commandes (CMD) via le parametre "User Configuration > Administrative Templates > System > Empecher l'acces a l'invite de commandes". Ce parametre a une option pour autoriser ou non le traitement des scripts batch. La seconde interdit l'acces au Panneau de configuration via "User Configuration > Administrative Templates > Control Panel > Interdire l'acces au Panneau de configuration et aux parametres PC". Ces restrictions empechent les stagiaires de modifier la configuration des postes de travail, ce qui reduit les risques de mauvaise manipulation.
Comment verifier qu'une GPO s'applique correctement ?
Il existe plusieurs methodes de verification. La commande "gpresult /r" sur le poste client affiche un resume de toutes les GPO appliquees a l'utilisateur et a l'ordinateur. La commande "gpresult /h rapport.html" genere un rapport HTML detaille. La commande "gpupdate /force" force la mise a jour immediate des GPO sans attendre le cycle de rafraichissement (par defaut 90 minutes). Dans la console GPMC, l'onglet "Resultant Set of Policy" (RSoP) permet de simuler l'application des GPO. Enfin, le test fonctionnel consiste a se connecter avec un compte stagiaire et verifier que CMD et le Panneau de configuration sont bien bloques.
Quelle difficulte avez-vous rencontree avec la GPO ?
La GPO ne s'appliquait pas sur le poste client malgre la liaison a l'OU Stagiaires. Apres investigation avec "gpresult /r", j'ai decouvert que le compte utilisateur etait reste dans l'OU "Users" par defaut au lieu d'etre dans l'OU "Stagiaires". Comme la GPO etait liee a l'OU Stagiaires, elle ne s'appliquait pas. J'ai deplace le compte dans la bonne OU puis execute "gpupdate /force" sur le poste client pour forcer l'application. Une deuxieme difficulte : la restriction CMD bloquait aussi les scripts batch automatises. J'ai configure l'option "Desactiver le traitement des scripts" sur "Non" pour autoriser l'execution des scripts tout en bloquant l'acces interactif a CMD.
Quels autres types de restrictions peut-on mettre en place avec les GPO ?
Les GPO offrent des centaines de parametres. On peut gerer les politiques de mot de passe (longueur minimale, complexite, expiration), configurer le pare-feu Windows, deployer des logiciels automatiquement (via MSI), rediriger les dossiers utilisateurs vers un serveur, configurer les parametres de proxy, activer BitLocker pour le chiffrement des disques, desactiver les peripheriques USB, configurer les mises a jour Windows via WSUS, personnaliser le bureau et le menu Demarrer, et bien plus. En entreprise, les GPO sont essentielles pour maintenir une configuration coherente et securisee sur l'ensemble du parc.

2.4 — Supervision Nagios (Ubuntu Server)

Epreuve E5 | Nagios Core | Apache + Perl + GD | IP 192.168.56.102 | Competences B1.2, B2.2, B2.3, B3.4
Qu'est-ce que Nagios et pourquoi est-ce important en entreprise ?
Nagios est un outil de supervision open source qui permet de surveiller en temps reel l'etat des serveurs, des services et des equipements reseau. Il verifie regulierement que les hotes sont accessibles (ping), que les services fonctionnent (HTTP, SSH, DNS, SMTP) et alerte l'administrateur en cas de panne ou de degradation de performance. En entreprise, la supervision est essentielle pour garantir la disponibilite des services : sans outil de monitoring, on decouvre les pannes quand les utilisateurs se plaignent, ce qui augmente le temps de resolution. Nagios permet de detecter proactivement les problemes et de les corriger avant qu'ils n'affectent les utilisateurs.
Pourquoi avoir compile Nagios depuis les sources plutot qu'un paquet APT ?
La compilation depuis les sources offre plusieurs avantages : on obtient la derniere version de Nagios Core (les depots APT contiennent souvent des versions plus anciennes), on peut personnaliser l'installation (repertoires, options de compilation), et on comprend mieux l'architecture du logiciel (dependances, fichiers de configuration). C'est aussi une competence technique valorisee en SISR : savoir compiler un logiciel depuis les sources sous Linux demontre une bonne maitrise de l'environnement. Le processus implique ./configure (verification des dependances), make all (compilation), make install (installation) et make install-config (fichiers de configuration par defaut).
Expliquez le role de l'utilisateur nagios et du groupe nagcmd.
L'utilisateur "nagios" est un compte systeme dedie qui execute le processus Nagios. Il est cree avec "useradd nagios" et ne dispose pas de shell de connexion pour des raisons de securite. Le groupe "nagcmd" (nagios command group) permet a l'utilisateur nagios et a l'utilisateur Apache (www-data) de communiquer via le fichier pipe de commandes externes. Cela permet a l'interface web d'envoyer des commandes a Nagios (acquitter une alerte, planifier une verification, desactiver les notifications). L'utilisateur www-data est ajoute au groupe nagcmd avec "usermod -aG nagcmd www-data".
Comment fonctionne l'authentification de l'interface web Nagios ?
L'interface web de Nagios utilise l'authentification HTTP Basic geree par Apache via le fichier htpasswd. La commande "htpasswd -c /usr/local/nagios/etc/htpasswd.users nagiosadmin" cree le fichier de mots de passe avec un premier utilisateur "nagiosadmin". Le mot de passe est stocke sous forme de hash. La configuration Apache de Nagios (fichier nagios.conf dans sites-enabled) contient les directives AuthType Basic et AuthUserFile qui pointent vers ce fichier. En production, il est indispensable d'activer HTTPS (certificat SSL) pour que les identifiants ne circulent pas en clair sur le reseau.
Quels modules Apache avez-vous du activer et pourquoi ?
J'ai du activer deux modules Apache. Le module mod_cgi permet a Apache d'executer les scripts CGI de Nagios qui generent les pages dynamiques de l'interface web (etat des hotes, historique, rapports). Sans ce module, les pages CGI renvoient une erreur 403 Forbidden. Le module mod_rewrite permet la reecriture d'URL, necessaire pour le fonctionnement correct des liens internes de l'interface Nagios. L'activation se fait avec "a2enmod cgi rewrite" suivi d'un redemarrage d'Apache avec "systemctl restart apache2". C'est exactement la difficulte que j'ai rencontree : l'interface affichait une erreur 403 avant l'activation de ces modules.
Quelle est la difference entre Nagios et d'autres outils comme Zabbix ou Grafana ?
Nagios est l'outil historique de supervision, tres flexible grace a ses plugins mais avec une interface web datee. Zabbix est une alternative plus moderne avec une interface graphique integree, une decouverte automatique des equipements et une base de donnees integree. Grafana n'est pas un outil de supervision a proprement parler mais un outil de visualisation de donnees qui s'interface avec des sources comme Prometheus, InfluxDB ou Zabbix pour creer des tableaux de bord. En entreprise, le choix depend des besoins : Nagios pour sa flexibilite et sa communaute, Zabbix pour une solution complete "all-in-one", Grafana pour des dashboards visuels avances.

2.5 — Telephonie VOIP Cisco (Packet Tracer)

Epreuve E5 | CME, 2x Routeur 2811, Switch 2960, 3x IP Phone 7960, 2x analogiques | Competences B2.1, B2.2, B2.3
Qu'est-ce que la VOIP et quels sont ses avantages par rapport a la telephonie classique ?
La VOIP (Voice Over IP) est une technologie qui permet de transmettre la voix sous forme de paquets numeriques sur le reseau IP, au lieu d'utiliser des lignes telephoniques analogiques dediees. Les avantages sont multiples : reduction des couts (pas besoin de cablage telephonique separe, appels entre sites gratuits via le reseau IP existant), flexibilite (ajout facile de postes telephoniques, mobilite des utilisateurs), fonctionnalites avancees (messagerie vocale, renvoi d'appels, conference, integration avec la messagerie email) et administration centralisee. L'inconvenient principal est la dependance au reseau IP : si le reseau tombe, la telephonie aussi.
Qu'est-ce que Cisco CME et comment l'avez-vous configure ?
Cisco CME (Call Manager Express) est une solution de telephonie IP integree dans les routeurs Cisco. Elle permet de gerer les telephones IP directement depuis le routeur, sans avoir besoin d'un serveur dedie. J'ai configure CME avec les parametres suivants : "max-ephones 10" pour definir le nombre maximum de telephones physiques, "max-dn 10" pour le nombre maximum de numeros de repertoire, "ip source-address 192.168.10.100 port 2000" pour definir l'adresse d'ecoute du service CME, "auto assign 1 to 10" pour l'attribution automatique des numeros aux telephones qui s'enregistrent, et "create cnf" pour generer les fichiers de configuration que les telephones telechargent via TFTP.
Comment les IP Phones obtiennent-ils leur configuration automatiquement ?
Le processus est automatise en plusieurs etapes. D'abord, le telephone IP obtient une adresse IP via DHCP. Le pool DHCP contient l'option 150 qui indique l'adresse du serveur TFTP (ici le routeur CME a 192.168.10.100). Le telephone telecharge alors son fichier de configuration CNF depuis le serveur TFTP. Ce fichier contient les parametres du CME (adresse IP, port, certificats). Enfin, le telephone s'enregistre aupres du CME sur le port 2000 et recoit son numero de repertoire. Dans mon projet, l'oubli de l'option 150 dans le pool DHCP a empeche les telephones de s'enregistrer, car ils ne savaient pas ou trouver le serveur TFTP.
Comment avez-vous integre les telephones analogiques ?
Les telephones analogiques sont connectes aux ports FXS (Foreign Exchange Station) des routeurs 2811. Les ports FXS fournissent la tonalite et l'alimentation aux telephones analogiques, comme le ferait une prise telephonique classique. Pour les integrer a l'infrastructure VOIP, j'ai configure des dial-peers POTS (Plain Old Telephone Service) qui associent chaque port FXS a un numero de repertoire (directory number). Ainsi, les telephones analogiques peuvent appeler et etre appeles par les IP Phones, comme s'ils faisaient partie du meme systeme telephonique. La difficulte a ete de configurer correctement les dial-peers pour router les appels entre les ports FXS et les ephones.
Qu'est-ce que la QoS et pourquoi est-elle importante en VOIP ?
La QoS (Quality of Service) est l'ensemble des mecanismes qui garantissent la qualite des communications voix sur un reseau IP. La voix est tres sensible a trois parametres : la latence (delai de transmission, doit etre inferieure a 150 ms), la gigue (variation de la latence, perturbante pour la voix) et la perte de paquets (doit etre inferieure a 1%). La QoS permet de prioriser le trafic voix par rapport aux autres types de trafic (navigation web, telechargements). Dans Packet Tracer, la QoS est limitee, mais en production, on configurerait des files de priorite, du marquage DSCP et du traffic shaping pour garantir la qualite des appels.
Quelle est la difference entre FXS et FXO ?
FXS (Foreign Exchange Station) et FXO (Foreign Exchange Office) sont deux types d'interfaces utilisees pour connecter la telephonie analogique au monde VOIP. Le port FXS fournit la tonalite et l'alimentation : c'est le port sur lequel on branche un telephone analogique. Le port FXO recoit la tonalite : c'est le port qu'on connecte a une ligne telephonique publique (PSTN). Dans mon projet, j'utilise des ports FXS pour connecter les 2 telephones analogiques au routeur. Si l'entreprise voulait se connecter au reseau telephonique public, elle utiliserait un port FXO pour recevoir la ligne de l'operateur.

Le DOM (Document Object Model) est la representation en memoire de la page HTML sous forme d'arborescence d'objets. JavaScript peut lire et modifier le DOM pour rendre la page interactive. Dans ma calculatrice, j'utilise "document.getElementById" pour recuperer les elements HTML (champs de saisie, zone de resultat). Chaque "case" contient l'operation correspondante et un "break" pour sortir du switch. Le "default" gere le cas ou l'operateur ne serait pas reconnu. En termes de bonnes pratiques, le switch/case est le pattern recommande pour ce type de logique de selection multiple.

2.7 — Analyse Reseau Wireshark (Linux)

Epreuve E5 | Wireshark, DNS, UDP | IP source 192.168.84.152 → 8.8.8.8 | Port 53433 → 53 | Competences B2.3, B3.4, B3.5
Qu'est-ce que Wireshark et a quoi sert-il ?
Wireshark est un analyseur de protocoles reseau open source, considere comme l'outil de reference pour la capture et l'analyse de trames. Il permet de capturer en temps reel tout le trafic qui passe sur une interface reseau, puis de l'analyser couche par couche selon le modele OSI. En entreprise, Wireshark est utilise pour diagnostiquer des problemes reseau (lenteurs, pertes de paquets), verifier la securite (detecter du trafic suspect), analyser les protocoles, et valider la configuration des equipements. C'est un outil indispensable pour tout technicien reseau et cybersecurite.
Expliquez l'analyse du paquet DNS que vous avez capture.
J'ai capture un paquet DNS avec les details suivants : au niveau de la couche 2 (Ethernet), les adresses MAC source et destination identifient les equipements locaux. Au niveau de la couche 3 (IP), l'adresse source est 192.168.84.152 (mon poste) et la destination est 8.8.8.8 (serveur DNS public de Google). Au niveau de la couche 4 (Transport), le protocole est UDP, le port source est 53433 (port ephemere attribue par le systeme) et le port destination est 53 (port standard du DNS). Au niveau de la couche 7 (Application), c'est une requete DNS de type A qui demande la resolution d'un nom de domaine en adresse IPv4. Cette analyse montre les 4 couches du modele TCP/IP en action.
Pourquoi le DNS utilise UDP et pas TCP ?
Le DNS utilise principalement UDP (port 53) car les requetes DNS sont petites (quelques centaines d'octets) et necessitent une reponse rapide. UDP est un protocole non connecte, sans mecanisme d'etablissement de connexion (pas de handshake TCP en 3 etapes), ce qui reduit la latence. La plupart des requetes DNS tiennent dans un seul paquet UDP. Cependant, le DNS utilise TCP dans deux cas : quand la reponse depasse 512 octets (ou 4096 avec EDNS) et pour les transferts de zone entre serveurs DNS (AXFR/IXFR). En resume, UDP pour la performance au quotidien, TCP quand la fiabilite est necessaire pour de gros volumes de donnees.
Pourquoi avoir du configurer les permissions avec usermod ?
Par defaut sous Linux, la capture de paquets reseau necessite des privileges root car elle implique la mise de l'interface en mode promiscuous (capture de tous les paquets, pas seulement ceux destines a la machine). Plutot que de lancer Wireshark en root (ce qui serait un risque de securite), on ajoute l'utilisateur au groupe "wireshark" avec la commande "sudo usermod -aG wireshark $USER". Ce groupe a les permissions necessaires via des capabilities Linux (CAP_NET_RAW, CAP_NET_ADMIN) pour capturer le trafic sans etre root. Il faut se deconnecter et se reconnecter pour que l'appartenance au nouveau groupe soit prise en compte.
Qu'est-ce que le modele OSI ? Combien de couches ?
Le modele OSI (Open Systems Interconnection) est un modele theorique a 7 couches qui decompose la communication reseau. De bas en haut : couche 1 (Physique) gere le signal electrique/optique, couche 2 (Liaison de donnees) gere les trames Ethernet et les adresses MAC, couche 3 (Reseau) gere les paquets IP et le routage, couche 4 (Transport) gere les segments TCP/UDP et les ports, couche 5 (Session) gere l'etablissement des sessions, couche 6 (Presentation) gere le chiffrement et la compression, couche 7 (Application) gere les protocoles applicatifs (HTTP, DNS, SMTP). Dans la pratique, on utilise souvent le modele TCP/IP a 4 couches qui fusionne les couches 5, 6 et 7.
Comment avez-vous filtre les paquets pour trouver le DNS ?
Wireshark offre deux types de filtres. Les filtres de capture (BPF) definis avant la capture limitent ce qui est enregistre (ex: "port 53"). Les filtres d'affichage, que j'ai utilises, filtrent les paquets deja captures. J'ai tape "dns" dans la barre de filtre d'affichage pour isoler uniquement les paquets du protocole DNS parmi les milliers de paquets captures. On peut aussi utiliser des filtres plus precis comme "dns.qry.name contains google" pour trouver les requetes vers un domaine specifique, ou "ip.addr == 8.8.8.8" pour voir tout le trafic vers le DNS de Google. La maitrise des filtres Wireshark est essentielle car une capture brute contient trop de paquets pour etre analysee manuellement.

Section 4 — Veille technologique : Le Phishing

Le jury evaluera ta capacite a faire de la veille, ta comprehension du sujet choisi, et ta methode de collecte d'informations. Prepare des chiffres et des exemples concrets.

Qu'est-ce que la veille technologique et pourquoi est-ce important en SISR ?
La veille technologique consiste a surveiller en continu les evolutions technologiques, les nouvelles menaces et les bonnes pratiques dans son domaine professionnel. Pour un technicien SISR, c'est indispensable car les cybermenaces evoluent en permanence : de nouvelles vulnerabilites sont decouvertes chaque jour, les techniques d'attaque se perfectionnent (notamment grace a l'IA), et les reglementations changent. Ma methode de veille se deroule en 4 etapes : je collecte les informations via les alertes ANSSI et CERT-FR, je trie ce qui concerne mon domaine, j'analyse les rapports officiels, et je documente mes decouvertes dans mon portfolio. Sans veille, un administrateur systeme risque de ne pas appliquer les correctifs de securite a temps ou de ne pas connaitre les nouvelles menaces.
Pourquoi avoir choisi le phishing comme sujet de veille ?
J'ai choisi le phishing car c'est la menace numero 1 en France selon le rapport Cybermalveillance 2025 : 108 000 demandes d'aide pour phishing en 2025, soit une hausse de 70% en un an. C'est un sujet qui touche autant les particuliers que les entreprises. En tant que futur technicien SISR, je serai en premiere ligne pour sensibiliser les utilisateurs et mettre en place des mesures de protection. Le phishing est aussi un sujet en pleine evolution avec l'apparition de l'IA generative qui rend les attaques beaucoup plus sophistiquees. Enfin, les attaques recentes en France (France Travail, Free, hopital de Cannes) montrent que le phishing a des consequences massives sur la societe.
Quels sont les differents types de phishing que vous avez etudies ?
J'ai identifie 8 formes de phishing. Le phishing par email (classique), le plus repandu avec 3,4 milliards d'emails frauduleux par jour dans le monde. Le smishing par SMS, en hausse de 2 500% en 2025 (faux colis, fausses amendes). Le vishing par telephone (faux conseillers bancaires, 245 millions d'euros voles en France). Le quishing par QR code, en hausse de 400% (faux PV, faux parcmetres). Le spear phishing cible, personalise grace aux reseaux sociaux (54% de taux de clic). Le whaling / fraude au president, ciblant les dirigeants (25 millions de dollars voles chez Arup par deepfake). Le phishing sur les reseaux sociaux (23% des attaques) avec de faux comptes SAV. Et le Evil Twin, un faux Wi-Fi public qui intercepte les donnees.
Comment l'intelligence artificielle a-t-elle change le phishing ?
L'IA a revolutionne le phishing de trois manieres. Premierement, le clonage de voix : avec seulement 3 secondes d'enregistrement, l'IA peut reproduire une voix avec 85% de precision (etude McAfee), permettant des arnaques telephoniques ou l'escroc se fait passer pour un proche. Deuxiemement, les emails parfaits : 82,6% des emails de phishing contiennent des elements generes par IA (rapport KnowBe4 2025). L'IA ecrit un email de phishing en 5 minutes contre 16 heures pour un humain, et les victimes cliquent 60% plus souvent sur un email ecrit par IA (etude Oxford). Troisiemement, les deepfakes video : en janvier 2024, l'entreprise Arup a perdu 25 millions de dollars suite a une visioconference ou tous les participants etaient des deepfakes. Les fraudes par deepfake ont augmente de 700% aux USA en 2025.
Citez des exemples concrets d'attaques de phishing recentes en France.
En mars 2024, France Travail (ex-Pole Emploi) a subi une attaque : les pirates ont vole les identifiants de conseillers Cap Emploi probablement par phishing, exposant les donnees de 43 millions de personnes (noms, numeros de secu, emails). En fevrier 2024, les plateformes de mutuelles Viamedis et Almerys ont ete compromises, exposant les donnees de sante de 33 millions de personnes. En octobre 2024, Free a subi un vol de donnees touchant 19,2 millions de clients et 5 millions d'IBAN, resultant en une amende CNIL de 42 millions d'euros. En avril 2024, l'hopital de Cannes a ete paralyse par un ransomware LockBit installe apres qu'un employe ait clique sur un lien piege, conduisant a la publication de 61 Go de donnees medicales sur le dark web.
Comment se proteger contre le phishing ?
J'ai identifie 6 mesures de protection. Ne jamais dechrocher les numeros inconnus pour empecher le clonage de voix par IA. Creer un mot de passe familial, un mot secret que seuls les proches connaissent pour verifier l'identite en cas d'appel suspect. Activer la double authentification (MFA) sur tous les comptes importants : meme si le mot de passe est vole, le pirate ne peut pas se connecter sans le deuxieme facteur. Toujours verifier l'adresse email de l'expediteur (pas juste le nom affiche) et ne jamais cliquer sur un lien dans un email. Ne jamais communiquer ses codes bancaires ou mots de passe. Signaler les arnaques : emails suspects a signal-spam.fr, SMS suspects au 33700, et sites frauduleux sur internet-signalement.gouv.fr.
Quels outils et sources utilisez-vous pour votre veille ?
J'utilise 6 sources officielles principales. Cybermalveillance.gouv.fr est le site gouvernemental d'aide aux victimes qui publie des alertes et des rapports annuels (504 000 demandes d'aide en 2025). L'ANSSI (Agence Nationale de la Securite des SI) publie le Panorama de la cybermenace et des guides techniques. Le CERT-FR est l'equipe d'alerte et de reponse aux cyberattaques en France qui publie des bulletins d'alerte 24h/24. La CNIL est l'autorite de protection des donnees personnelles qui publie les sanctions et les enquetes RGPD. Signal Spam permet de signaler les emails frauduleux. Le 33700 permet de signaler les SMS frauduleux. J'utilise aussi les rapports annuels de KnowBe4, Proofpoint et McAfee pour les statistiques mondiales.
Quel est le cadre legal autour du phishing ? Que dit le RGPD ?
Le phishing est un delit puni par le Code penal francais : l'usurpation d'identite en ligne est punie de 1 an d'emprisonnement et 15 000 euros d'amende (article 226-4-1), et l'escroquerie est punie de 5 ans et 375 000 euros. Le RGPD (Reglement General sur la Protection des Donnees) impose aux organisations de proteger les donnees personnelles sous peine de sanctions pouvant atteindre 4% du chiffre d'affaires mondial. La CNIL est l'autorite de controle en France : elle a sanctionne Free de 42 millions d'euros en janvier 2026 suite a la fuite de donnees. Depuis le 1er janvier 2026, une nouvelle loi anti-spoofing force les appels etrangers avec faux numero francais a s'afficher "numero masque" pour lutter contre le vishing.
Comment reperer un email de phishing ?
Il y a 5 signaux d'alerte. L'adresse email suspecte : "support@microsft-security.com" au lieu de "microsoft.com" — il faut toujours regarder l'adresse complete, pas juste le nom affiche. La mise sous pression : "Votre compte sera bloque dans 24h" — les escrocs veulent que vous agissiez vite sans reflechir. Le lien suspect : en passant la souris sur le lien sans cliquer, on voit que l'URL ne correspond pas au vrai site. L'absence de personnalisation : "Cher client" au lieu de votre vrai nom, ce qui indique un envoi en masse. La demande d'informations sensibles : aucune banque ni administration ne demande de mot de passe ou code de carte par email. Aujourd'hui avec l'IA, le critere des fautes d'orthographe n'est plus fiable car les emails generes par IA sont parfaitement rediges.
Quel lien faites-vous entre votre veille sur le phishing et vos certifications ?
Mes deux certifications sont directement liees a ma veille. La certification SecNumacademie de l'ANSSI, avec ses 4 modules (panorama de la SSI, authentification, securite sur Internet, securite du poste de travail), m'a donne les bases theoriques pour comprendre les mecanismes du phishing et les mesures de protection. La certification Cisco Introduction to Cybersecurity couvre les fondamentaux de la cybersecurite, les menaces et vulnerabilites, la protection des donnees et la securite des reseaux, ce qui me permet de contextualiser le phishing dans le paysage global des cybermenaces. Ces certifications valident ma competence en cybersecurite et montrent que je ne me contente pas de faire de la veille passive, mais que je me forme activement sur les sujets que j'etudie.

Section 5 — Questions generales BTS SIO SISR

Ces questions peuvent tomber a tout moment pendant l'oral. Elles testent ta culture technique et ta comprehension des fondamentaux reseaux et systemes.

Pourquoi avoir choisi l'option SISR plutot que SLAM ?
J'ai choisi SISR car je suis passionne par l'infrastructure reseau, l'administration systeme et la cybersecurite. J'aime comprendre comment les systemes fonctionnent "sous le capot" : configurer un reseau, deployer un serveur, securiser une infrastructure. L'option SLAM est orientee developpement d'applications, ce qui m'interesse moins que la gestion d'infrastructure. De plus, le secteur des reseaux et de la cybersecurite offre d'excellentes perspectives d'emploi : avec la hausse des cybermenaces (+70% de phishing en 2025), les entreprises ont un besoin croissant de techniciens capables de securiser et d'administrer leurs infrastructures.
Quelle est la difference entre SISR et SLAM ?
SISR (Solutions d'Infrastructure, Systemes et Reseaux) forme des techniciens qui installent, configurent et maintiennent les serveurs, les reseaux, la virtualisation et la securite des infrastructures informatiques. Le quotidien d'un technicien SISR inclut l'administration de serveurs Windows et Linux, la configuration de routeurs et switches, la mise en place de VPN, la supervision reseau et la cybersecurite. SLAM (Solutions Logicielles et Applications Metier) forme des developpeurs qui concoivent, codent et maintiennent des applications web, mobiles et de bureau. Ils travaillent avec des langages de programmation (Java, PHP, Python), des bases de donnees (SQL) et des frameworks. Les deux options partagent un socle commun (B1 Support et B3 Cybersecurite) mais different sur le bloc B2.
Qu'est-ce que le modele OSI ? Citez les 7 couches.
Le modele OSI (Open Systems Interconnection) est un modele de reference theorique a 7 couches qui standardise la communication reseau. Couche 1 Physique : les signaux electriques, cables, connecteurs (RJ45, fibre optique). Couche 2 Liaison de donnees : les trames, adresses MAC, switches, protocole Ethernet. Couche 3 Reseau : les paquets, adresses IP, routage, routeurs. Couche 4 Transport : les segments, ports TCP/UDP, controle de flux. Couche 5 Session : etablissement et maintien des sessions de communication. Couche 6 Presentation : chiffrement, compression, encodage des donnees. Couche 7 Application : les protocoles utilisateurs comme HTTP, DNS, SMTP, FTP. En pratique, le modele TCP/IP a 4 couches est plus utilise : Acces reseau, Internet, Transport, Application.
Expliquez le processus DORA du DHCP.
DORA est l'acronyme des 4 etapes de l'attribution d'une adresse IP par DHCP. Discovery : le client envoie un message broadcast DHCPDISCOVER sur le reseau pour trouver un serveur DHCP (il n'a pas encore d'IP, il utilise 0.0.0.0 comme source et 255.255.255.255 comme destination). Offer : le serveur DHCP repond avec un DHCPOFFER contenant une adresse IP proposee, le masque, la passerelle et le serveur DNS. Request : le client accepte l'offre en envoyant un DHCPREQUEST en broadcast (car il peut y avoir plusieurs serveurs DHCP). Acknowledge : le serveur confirme l'attribution avec un DHCPACK. L'adresse est attribuee pour une duree definie (le bail/lease), apres quoi le client doit la renouveler. Ce mecanisme permet une gestion centralisee et automatisee de l'adressage IP.
Qu'est-ce qu'un VLAN ? A quoi sert un trunk ? Qu'est-ce que le 802.1Q ?
Un VLAN (Virtual LAN) est un reseau local virtuel qui segmente logiquement un reseau physique. Les postes dans le meme VLAN communiquent comme s'ils etaient sur le meme switch, meme s'ils sont physiquement eloignes. Les avantages sont la securite (isolation des flux), la performance (reduction du broadcast) et la flexibilite (reorganisation sans recablage). Un trunk est un lien reseau qui transporte le trafic de plusieurs VLAN simultanement, generalement entre deux switches ou entre un switch et un routeur. Le 802.1Q est le protocole IEEE de marquage des trames : il ajoute un tag de 4 octets dans l'en-tete Ethernet contenant le VLAN ID (1-4094), ce qui permet d'identifier a quel VLAN appartient chaque trame sur un trunk. Le VLAN natif est celui dont les trames ne sont pas taguees.
Expliquez ce qu'est Active Directory et a quoi il sert.
Active Directory est le service d'annuaire de Microsoft qui centralise la gestion de tous les objets d'un reseau d'entreprise : utilisateurs, groupes, ordinateurs, imprimantes et politiques de securite. Il repose sur une structure hierarchique (foret > domaine > OU) et utilise les protocoles LDAP (consultation de l'annuaire), Kerberos (authentification) et DNS (localisation des services). L'interet principal est la centralisation : au lieu de gerer chaque poste individuellement, l'administrateur cree les comptes et applique les politiques depuis un seul point (le controleur de domaine). Un utilisateur se connecte avec ses identifiants AD sur n'importe quel poste du domaine et retrouve ses droits d'acces. Les GPO permettent d'appliquer des configurations uniformes a l'ensemble du parc.
C'est quoi une GPO ? Donnez des exemples d'utilisation.
Une GPO (Group Policy Object) est un ensemble de parametres de configuration appliques automatiquement aux utilisateurs ou aux ordinateurs d'un domaine Active Directory. Elles sont creees dans la console GPMC et liees a des OU, des domaines ou des sites. Exemples d'utilisation : politique de mot de passe (longueur minimale 12 caracteres, complexite obligatoire, expiration tous les 90 jours), deploiement automatique de logiciels (MSI), redirection des dossiers utilisateurs vers un serveur (Bureau, Documents), configuration du pare-feu Windows, blocage de l'acces a CMD ou PowerShell pour certains utilisateurs, configuration du fond d'ecran et du menu Demarrer, activation du chiffrement BitLocker, configuration des mises a jour WSUS. Les GPO sont essentielles pour la securite et la coherence du parc informatique.
Expliquez le fonctionnement du DNS.
Le DNS (Domain Name System) est le systeme qui traduit les noms de domaine lisibles par l'homme (google.com) en adresses IP (142.250.74.238). Le processus de resolution fonctionne ainsi : le client interroge son serveur DNS local (recursif), qui verifie son cache. S'il n'a pas la reponse, il interroge un serveur racine (.) qui redirige vers le serveur TLD (.com, .fr), qui redirige vers le serveur autoritaire du domaine, qui renvoie l'adresse IP. Le resultat est mis en cache pour accelerer les futures requetes (duree definie par le TTL). Le DNS utilise le port 53, principalement en UDP pour les requetes simples et en TCP pour les transferts de zone. Les types d'enregistrements courants sont A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail), NS (serveur de noms), PTR (inverse) et SRV (services).
Comment fonctionne un VPN ?
Un VPN (Virtual Private Network) cree un tunnel chiffre entre deux points sur un reseau non securise (Internet). Le principe est l'encapsulation : les paquets de donnees originaux sont chiffres et encapsules dans de nouveaux paquets qui transitent sur Internet. Seuls les deux extremites du tunnel (le client VPN et le serveur VPN) peuvent dechiffrer le contenu. Les protocoles VPN les plus courants sont OpenVPN (open source, port 1194), IPSec (souvent combine avec L2TP), WireGuard (plus recent et performant) et SSL/TLS VPN. En entreprise, le VPN permet aux employes en teletravail d'acceder au reseau interne de maniere securisee, comme s'ils etaient physiquement au bureau. Il protege aussi la confidentialite des communications sur les reseaux Wi-Fi publics.
Qu'est-ce que la cybersecurite ? Quelles sont les menaces principales ?
La cybersecurite est l'ensemble des pratiques, technologies et processus visant a proteger les systemes informatiques, les reseaux et les donnees contre les acces non autorises, les attaques et les dommages. Les menaces principales sont : le phishing (108 000 cas en France en 2025), les ransomwares (logiciels qui chiffrent les donnees et demandent une rancon, comme LockBit qui a touche l'hopital de Cannes), les fuites de donnees (France Travail, Free), les attaques par force brute sur les mots de passe, les attaques DDoS (deni de service distribue), les malwares (virus, trojans, spywares), l'ingenierie sociale, et les vulnerabilites zero-day. La cybersecurite repose sur trois piliers : la confidentialite, l'integrite et la disponibilite des donnees (triade CIA).
Qu'est-ce que le RGPD ? Quelles sont ses obligations principales ?
Le RGPD (Reglement General sur la Protection des Donnees) est un reglement europeen entre en vigueur en mai 2018 qui encadre le traitement des donnees personnelles. Ses principes cles sont : le consentement eclaire de l'utilisateur, la minimisation des donnees (ne collecter que le necessaire), la limitation de conservation, la securite des donnees, et le droit des personnes (acces, rectification, effacement, portabilite). Les entreprises doivent nommer un DPO (Data Protection Officer) si elles traitent des donnees sensibles, tenir un registre des traitements, et notifier la CNIL dans les 72h en cas de violation de donnees. Les sanctions peuvent aller jusqu'a 4% du chiffre d'affaires mondial ou 20 millions d'euros. En France, la CNIL est l'autorite de controle et a sanctionne Free de 42 millions d'euros en 2026.
Quelle est la difference entre TCP et UDP ?
TCP (Transmission Control Protocol) et UDP (User Datagram Protocol) sont les deux protocoles de la couche Transport. TCP est un protocole connecte et fiable : il etablit une connexion en 3 etapes (SYN, SYN-ACK, ACK), garantit la livraison des donnees (acquittements, retransmissions), et assure l'ordre des paquets. Il est utilise pour HTTP, HTTPS, SMTP, FTP, SSH. UDP est un protocole non connecte et non fiable : il envoie les paquets sans verification de reception ni d'ordre, ce qui le rend plus rapide mais sans garantie de livraison. Il est utilise pour DNS (requetes simples), DHCP, VOIP, streaming video, et jeux en ligne. Le choix entre TCP et UDP depend du besoin : fiabilite (TCP) ou rapidite (UDP).
Qu'est-ce que la virtualisation et quel est son interet ?
La virtualisation est la technologie qui permet de creer des machines virtuelles (VM) sur un seul serveur physique, grace a un hyperviseur. Chaque VM dispose de son propre systeme d'exploitation, de ses ressources (CPU, RAM, stockage) et fonctionne de maniere isolee des autres. Les avantages sont : la consolidation des serveurs (un seul serveur physique peut heberger 5-10 VM), la reduction des couts d'infrastructure et d'energie, la flexibilite (creation et suppression rapide de VM), les snapshots (sauvegarde instantanee de l'etat d'une VM), et la haute disponibilite (migration des VM entre serveurs). Les hyperviseurs les plus courants sont VMware vSphere, Microsoft Hyper-V, Proxmox (que j'utilise dans ma formation) et VirtualBox. La virtualisation est la base du cloud computing.
Qu'est-ce qu'un pare-feu et comment fonctionne-t-il ?
Un pare-feu (firewall) est un equipement ou logiciel de securite qui filtre le trafic reseau entrant et sortant selon des regles predefinies. Il se place entre le reseau interne (de confiance) et le reseau externe (Internet, non securise). Le filtrage peut se faire par adresse IP source/destination, par port (ex: autoriser le port 80/443 pour le web, bloquer tout le reste), par protocole, ou par etat de connexion (stateful inspection). Les pare-feux modernes integrent aussi la detection d'intrusion (IDS/IPS), le filtrage applicatif (couche 7) et le VPN. Dans ma formation, j'ai travaille avec pfSense (pare-feu open source) et iptables (pare-feu Linux). En entreprise, le pare-feu est la premiere ligne de defense du reseau.
Qu'est-ce que le subnetting ? Donnez un exemple.
Le subnetting (sous-reseautage) est la technique qui consiste a diviser un reseau IP en sous-reseaux plus petits. Par exemple, le reseau 192.168.1.0/24 (256 adresses) peut etre divise en 4 sous-reseaux /26 de 64 adresses chacun : 192.168.1.0/26 (0-63), 192.168.1.64/26 (64-127), 192.168.1.128/26 (128-191), 192.168.1.192/26 (192-255). Le masque /26 correspond a 255.255.255.192. Le subnetting permet d'optimiser l'utilisation des adresses IP, de reduire les domaines de broadcast, et de segmenter le reseau pour des raisons de securite. Pour calculer, il faut connaitre les puissances de 2 : /24 = 256 adresses, /25 = 128, /26 = 64, /27 = 32, /28 = 16. On soustrait 2 (adresse reseau et broadcast) pour obtenir le nombre d'hotes utilisables.

Qu'est-ce que le protocole SNMP ?
SNMP (Simple Network Management Protocol) est un protocole de supervision qui permet de collecter des informations et de gerer les equipements reseau a distance. Il fonctionne avec un systeme de manager (la station de supervision comme Nagios) qui interroge les agents SNMP installes sur les equipements (routeurs, switches, serveurs). Chaque equipement dispose d'une MIB (Management Information Base) qui contient les variables surveillees (utilisation CPU, memoire, trafic reseau, etat des interfaces). SNMP utilise le port UDP 161 pour les requetes (GET, SET) et le port 162 pour les alertes (TRAP). Il existe 3 versions : SNMPv1 et v2c utilisent des community strings en clair, tandis que SNMPv3 ajoute l'authentification et le chiffrement. Dans ma formation, j'ai utilise SNMP avec Nagios via le plugin NRPE pour superviser les serveurs distants.
Qu'est-ce qu'une adresse MAC ? Une adresse IP ? Quelle difference ?
L'adresse MAC (Media Access Control) est un identifiant physique unique grave dans la carte reseau de chaque equipement, codee sur 48 bits (6 octets) en hexadecimal (ex: AA:BB:CC:DD:EE:FF). Les 3 premiers octets identifient le fabricant (OUI). Elle opere a la couche 2 du modele OSI et est utilisee pour la communication locale sur un meme reseau (segment Ethernet). L'adresse IP (Internet Protocol) est un identifiant logique attribue par un administrateur ou par DHCP, codee sur 32 bits pour IPv4 (ex: 192.168.1.100) ou 128 bits pour IPv6. Elle opere a la couche 3 et permet le routage entre differents reseaux. La difference cle : l'adresse MAC identifie l'equipement physique de maniere permanente, tandis que l'adresse IP identifie sa position logique dans le reseau et peut changer.
